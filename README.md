**LimitApp** — современное мобильное приложение на **Python (Flet / Flutter Engine)**, **SymPy** и **Google Gemini AI**, превращающее обычный калькулятор в интерактивного **умного репетитора по математическому анализу**.

## ✨ Ключевые возможности v1.6.0

### 1. 📷 Ввод примера по фото (OCR через Gemini Vision)
- Сфотографируйте рукописный или печатный пример из тетради или учебника.
- Нейросеть Google Gemini Vision автоматически распознает математический предел, извлечет функцию $f(x)$, переменную, точку стремления $x_0$ и знак, мгновенно заполнив поля ввода.

### 2. 🔬 Визуальный и тактильный «Режим исследования» (Лаборатория)
- **Тактильный ползунок приближения ($x \to a$):** ведите палец по экрану, приближая точку к пределу слева и справа. В реальном времени бегут цифры: текущий $x$, шаг $\Delta x$, значение функции $f(x)$ и шкала сходимости $|f(x) - L|$.
- **Визуализация определения Коши ($\varepsilon$ - $\delta$):** сужайте горизонтальный коридор $\varepsilon$ вокруг предела $L$ — приложение автоматически рассчитывает ширину интервала $\delta$ по оси $X$, гарантирующую попадание графика в заданные рамки.
- **Карта разрывов и выколотых точек:** автоматическая классификация типа особенности в точке (устранимый разрыв / выколотая точка, разрыв 1-го рода со скачком $\Delta$, разрыв 2-го рода / асимптота) с подробным описанием поведения функции.

### 3. 🎓 Умный AI-репетитор и педагогика
- **Деконструкция неопределенностей:** точный математический диагноз перед решением — почему прямая подстановка приводит к $[0/0]$ или $[\infty/\infty]$ и какая стратегия раскрытия строго необходима.
- **Сравнение 3 методов решения (Alternative Paths):**
  1. *⚡ Быстрый способ (Правило Лопиталя)* — дифференцирование числителя и знаменателя.
  2. *📐 Классический способ (Замечательные пределы и эквивалентности)* — классика для строгих вузовских преподавателей.
  3. *🔬 Асимптотический способ (Ряд Тейлора)* — разложение до малых $o(x^n)$.
- **Тренажер «Найди ошибку в моем решении»:** введите свой шаг или ответ своими словами, а AI-репетитор проверит математическую строгость, укажет на потерянный минус или незаконное применение эквивалентности и подскажет правильный ход мысли.
- **Закрепление материала (Practice Mode):** автоматическая генерация 3 похожих задач для тренировки с полем ввода и мгновенной самопроверкой.

### 4. 📋 Экспорт в LaTeX
- Копирование чистого профессионального LaTeX-кода формулы и пошагового решения для быстрой вставки в курсовые, дипломные работы и статьи.

### 5. ⚡ Мощный аналитический движок (SymPy 100% оффлайн)
- Решение абсолютно любых существующих пределов (алгебраические, тригонометрические, показательные, логарифмические, факториалы $n!$, корни, последовательности).
- Раскрытие всех 7 типов неопределенностей: $[0/0]$, $[\infty/\infty]$, $[1^\infty]$, $[0 \cdot \infty]$, $[\infty - \infty]$, $[0^0]$, $[\infty^0]$.
- Односторонние пределы ($x \to x_0^+$, $x \to x_0^-$) и таблица окрестностей $\varepsilon$.

### 6. 📱 Исправление всех багов и эргономичный интерфейс
- Полностью исправлено копирование в буфер обмена (`ft.Clipboard`).
- Двухуровневая компоновка главных кнопок исключает вылезание текста на экранах любой ширины (320px–440px+).
- Удобная клавиатура с клавишами 42px и символом $\infty$ на основной буквенно-цифровой раскладке.
- Модальное окно подтверждения очистки истории.

## 📥 Установка и запуск

### 📱 Android
Скачайте готовый `.apk` из раздела [Releases](https://github.com/MaloyDevil/limitapp/releases/latest) и установите на смартфон.

### 💻 Запуск из исходников
```bash
git clone https://github.com/MaloyDevil/limitapp.git
cd limitapp
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
