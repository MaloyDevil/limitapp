**LimitApp** — современное мобильное приложение на **Python (Flet / Flutter)**, **SymPy** и **Google Gemini AI** для аналитического вычисления математических пределов любой сложности с пошаговыми объяснениями, автоматическим распознаванием неопределенностей, интерактивным справочником формул и численной таблицей сходимости.

> **Создатель:** Нарницкий Роман  
> **Никнейм:** Syrok  
> **Версия:** 1.4.0 AI Pro

## ✨ Основные возможности v1.5.0

1. **🤖 Интеграция с Google Gemini AI (Бесплатный API):**
   - Интеллектуальный преподавательский разбор пределов любой сложности с подробными математическими формулами и пояснениями.
   - Поддержка актуальных моделей: `Gemini 3.1 Flash-Lite` (быстрая и бесплатная), `Gemini 3.5 Flash-Lite` (новейший ИИ) и `Gemini 3.8 Flash` (глубокий анализ).
   - Встроенное окно настроек API-ключа с проверкой статуса подключения и ссылкой на получение бесплатного ключа в Google AI Studio.
   - Кнопка моментальной сверки аналитического решения SymPy с объяснением искусственного интеллекта.

2. **🎨 Кардинально обновленный и удобный ввод формул:**
   - **Интерактивные шаблоны задач в 1 клик:** быстрые чипы для дробей `a/b`, корней `√x`, степеней `xⁿ`, модулей `|x|`, замечательных пределов `sin(x)/x`, `(1+1/x)ˣ`, `(eˣ-1)/x`, `ln(1+x)/x`, `tg(x)` и `n!`.
   - **Двухуровневая математическая клавиатура:** удобные вкладки `🔢 123 / Алгебра` и `📐 f(x) Функции`. Крупные удобные кнопки, быстрый ввод степеней $x^2, x^3, e^x$ и дробей $1/x$.
   - **Живой математический предпросмотр:** карточка с аккуратной нотацией $\lim_{x \to x_0} [ f(x) ]$.
   - Быстрые чипы переменных (`x`, `n`, `t`, `y`), предельных точек (`0`, `+∞`, `-∞`, `1`, `-1`, `π`, `π/2`, `e`) и знаков односторонних пределов.

3. **Решение любого существующего предела (SymPy движок):**
   - Двусторонние пределы: $\lim_{x \to x_0} f(x)$
   - Односторонние пределы: правосторонний ($x \to x_0^+$) и левосторонний ($x \to x_0^-$)
   - Пределы на бесконечности ($x \to +\infty$, $x \to -\infty$, $x \to \infty$)
   - Пределы числовых последовательностей с переменной $n \to \infty$
   - Полноценная поддержка LaTeX-синтаксиса (`\frac{...}{...}`, `\sqrt{...}`, `\cdot`, `\infty`, `\pi`)
   - Поддержка тригонометрических степеней (`sin^2(x)`, `cos^3(x)`), скобок `[...]` и `{...}`, факториалов `n!`, модулей `|x|` и десятичных запятых `0,5`
   - Автоматический парсинг скопированных строк пределов (`lim (x->0) ...`, `lim_{n->oo} ...`)

4. **Анализ всех 7 типов неопределенностей:**
   - Автоматическое определение классических неопределенностей математического анализа:
     $$\left[\frac{0}{0}\right], \quad \left[\frac{\infty}{\infty}\right], \quad [0 \cdot \infty], \quad [\infty - \infty], \quad [1^\infty], \quad [0^0], \quad [\infty^0]$$

5. **Пошаговое объяснение решения:**
   - Подстановка предельной точки и проверка непрерывности
   - Применение Правила Лопиталя (дифференцирование числителя и знаменателя)
   - Сведение к замечательным пределам
   - Разложение в ряд Тейлора (асимптотическое приближение)
   - Сравнение левого и правого пределов для доказательства существования предела

6. **Таблица численного приближения (демонстрация сходимости):**
   - Расчет значений функции $f(x)$ в $\varepsilon$-окрестности точки $x_0$ слева и справа.

7. **Интерактивный справочник формул:**
   - Первый и второй замечательные пределы и их следствия
   - Таблица эквивалентных бесконечно малых при $\alpha \to 0$
   - Таблица методов раскрытия неопределенностей
   - Кнопка **«Решить в калькуляторе»** у каждого примера для моментальной загрузки и решения в один клик.

8. **История вычислений и избранное:**
   - Локальное сохранение истории расчетов
   - Закладки ⭐ Избранное
   - Быстрое восстановление любого предела по нажатию.

9. **Современный мобильный UI (Material Design 3):**
   - Переключение Темной и Светлой темы
   - Удобная нижняя панель навигации (Bottom Navigation Bar)
   - Кнопка копирования полного решения в буфер обмена
   - Новая Android Adaptive Icon, ровно и красиво вырезанная под любой лаунчер смартфона.

## 🚀 Запуск на компьютере (локально)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/MaloyDevil/limitapp.git
   cd limitapp
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение:
   ```bash
   python main.py
   ```
